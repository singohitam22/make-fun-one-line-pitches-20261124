One sentence to convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> You've got the idea and I've got ten minutes, so let's put it in together and see something real on the screen before you talk yourself out of it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-sentence pitch to `out/entry.txt` (UTF-8, 1–240 characters, a single sentence).
